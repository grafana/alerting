# Alerting

This library contains utilities that are useful for building Alerting systems.

## Current state

This library is still in development.

## Mimir compatibility

The Legacy (`v0mimir1`/`v0mimir2`) integrations are compatible with Grafana Mimir up to 3.0.x. Mimir 3.1 and later use newer upstream Prometheus Alertmanager versions. Their configurations can include integrations and fields that the Legacy integrations do not yet support. See [compatibility tracking](https://github.com/grafana/alerting/issues/694).
